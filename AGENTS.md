## Learned User Preferences

- Prefer Bun tooling in commands and docs (`bunx`, `bun run`) over `npx`/`npm run`.

## Learned Workspace Facts

- The About section includes email and X contact links; the page has no separate Connect section or live clock.
- Portfolio presentation should avoid arrow/link icon embellishments, and the works list should exclude the Ato project.

## Testing

- Run the existing Bun suite with `bun test` (tests live under `tests/`).
- Run `bun run check`, `bun run lint`, `bun run check:format`, and `bun run build` before shipping.
